1. **官方导入**：`plugin-import-2x@1.1.10` 完成场景/预制体/资源/脚本骨架转换（game.scene 452 节点、loading.scene、21 预制体、129 图、音频、3 龙骨），UUID 全保留 → 场景引用不断。

## 八、黑屏与标签页崩溃修复（2026-10-16 用户报障回归）

### 1. 事故链
| 现象 | 根因 | 修复 |
|---|---|---|
| 重启黑屏（canvas 全黑、日志面板正常） | v1 渲染器 hook 对 `!renderData` early-return 吞 Mask stencil 渲染 | 移除宽条件 hook；引擎原版已自拦 !renderData，外层只允许精确条件 |
| 满级启动标签页直接死（about:blank） | FILLED/RADIAL/TILED fillRange=0 → 0 顶点 → chunk 永久 null → 每帧 vb 崩 → 渲染循环中断 → byteOffset 累积 39M → RangeError | 六层防线（下表） |
| 验收假绿 | 只看 console 错误数，页面已崩时 console 为空 | 验收三件套：error 计数 + 页面存活校验 + 截图肉眼确认 |

### 2. 终版防线（common/NodeCompat.ts）
1. `Sprite.fillRange` setter hook：非 SIMPLE 填充赋 0 → clamp 0.001（赋值源头零窗口）。
2. `Sprite.onEnable` hook：空帧补 256×256 透明兜底帧（rect/offset/originalSize 齐设、packable=false）+ fillRange clamp + assembler 原型 hook（退化帧/无 chunk 帧跳过当帧，正常帧透传）。
3. `RenderData.resize`/`dataLength` setter 熔断：>50000 顶点降级单 quad 并记录调用栈。
4. `MeshBuffer.uploadBuffers` 熔断：byteOffset 超 vData 容量即复位计数（丢一帧保标签页）。
5. `window.onerror`：捕获 typed array 异常复位全部 MeshBuffer，防错误滚雪球。
6. 场景后 sweep（0.3s/1.5s/4s + 每 2s）补帧兜底。

### 3. 业务 null guard 补充
- Loo_item：circle/spr/initPar/add_fallings 四处引用 guard。
- Staff/Loo_item：fillRange 重置 0 → 0.001。
