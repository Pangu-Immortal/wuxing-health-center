## 三、执行中发现并修复的问题（游戏本体 1 处 + 测试设施若干）

1. **GameSys.game 首读为 null（游戏本体）**：`init()` 为 async，业务组件 onLoad 早于 init 完成时 `game.xBind/xGet` 崩溃（T12 曾报 64 次）。修复：getter 内先调幂等同步引导 `bootSync()`。文件：`assets/script/common/manager/GameSys.ts`。
2. **Chrome for Testing 主进程崩溃（环境）**：排查期追加的 `--disable-dev-shm-usage`/swiftshader 启动参数导致 Chrome 155 在 macOS 26.6 上启动 5s 内 EXC_BREAKPOINT 崩溃（系统崩溃报告为证）。回退后仅保留 `--no-sandbox`，脚本头部已写入参数红线。
3. **测试设施修正**：console 计数改按步骤增量（reload 不清缓冲导致跨用例污染）；EVALR 增加空值/错误自愈重试与标签页重开；T04/T05 改程序化事件触发（绕过相机投影坐标差异）；T04 断言改为"扣金或升级计时启动"（升级为计时制，等级延迟生效）。

## 五、追加修复：损坏存档异常日志根除（21:00-21:20，用户报障"大量异常日志没修复"）

### 1. 根因链（堆栈实证）
`Caches.get` 裸 `JSON.parse` 读存档 → 坏串抛 SyntaxError（104 连发）→ 中断 `new Game()` →
`GameSys._game` 永久 null → 后续 `game.xGet/xBind`、`.node`、`.active` 连锁崩溃（3+2+1）。
此前 T10 只断言"标签页不崩"，放过了这些异常——断言标准不足，已加强为"error 增量=0"。

### 2. 修复清单
| 文件 | 修复 |
|---|---|
| common/manager/Caches.ts | get：try/catch + 坏键 removeItem + 回退默认值（warn 级提示）；getInt/getFloat：NaN 回退默认值 |
| common/net/Http.ts:118 | 响应裸 parse 加 try/catch，非 JSON 响应 warn 后 return（不中断回调链） |
| common/sdk/SDK.ts:59 | catch 内 `JSON.parse(err)`（Error 对象必抛）改为直接 log err |

### 3. 验证
