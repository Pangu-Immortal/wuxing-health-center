# 五星卫生院 · 双引擎版本开源

竖屏放置经营小游戏《五星卫生院》的完整开源工程，含两个引擎版本：

| 目录 | 引擎版本 | 说明 |
|---|---|---|
| [五星卫生院-2.4.12/](五星卫生院-2.4.12/) | Cocos Creator 2.4.12 | 原始版本（TypeScript，cc.Class 体系） |
| [五星卫生院-3.8.8/](五星卫生院-3.8.8/) | Cocos Creator 3.8.8 | 迁移版本（TypeScript 严格模式，含原生 Android 适配与自动化测试基建） |

![主场景](五星卫生院-3.8.8/screenshots/main.png)

## 游戏一句话
接管仙界卫生院，建设/补货/招募/打扫，把它经营成五星卫生院——纯离线单机放置经营。

## 关键事实
- **纯离线**：无网络请求、无广告、无登录、无内购。
- **全流程 AI 独立完成**：游戏设计 → UI 图产出 → 代码实现 → 自动化测试，全部由 **WorkBuddy** 独立完成。
- **模型**：HY3 免费版。
- **研发耗时**：6 小时。

## 玩法速览（详见各版本 README）
- 核心循环：顾客消费产金 → 设施脏污 → 道具/员工打扫 → 金币升级房间 → 解锁新区域。
- 成长线：LV1→LV39；12 房间×3 级、10 道具、13 商品、8 员工、34 外观、10 房间解锁 = 通关态。
- 新手引导：32 步「仙界教学」镂空手势引导。

## 运行
- 2.4.12 版：Cocos Creator 2.4.12 打开 `五星卫生院-2.4.12/` → 预览。
- 3.8.8 版：Cocos Creator 3.8.8 打开 `五星卫生院-3.8.8/` → 预览；Android 打包需 NDK r27b + JDK 21。
